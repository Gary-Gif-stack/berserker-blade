# Berserker Blade (Fabric 1.21.1)

Requires Java 21 and Fabric API 0.102.0+1.21.1.

Build:   ./gradlew build        -> build/libs/berserker-blade-1.0.0.jar
Run dev: ./gradlew runClient

Give yourself the sword: /give @s berserker:berserker_blade
Rage key: R (rebind under Controls > Berserker Blade)
All numbers are in src/main/java/com/berserker/Balance.java
